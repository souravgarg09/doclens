# Demo PDFs

Put born-digital PDFs here for demos and for the benchmark (`backend/scripts/benchmark.py` uses
the first PDF in this folder unless `--pdf` is given). PDFs in this folder are not committed:
research papers are usually copyrighted.

Papers used while developing DocLens (download them yourself):

- Krieger, J. W. (2010). Single vs. multiple sets of resistance exercise for muscle hypertrophy: a
  meta-analysis. *Journal of Strength and Conditioning Research*, 24(4), 1150-1159.
  Save as `muscle-hypertrophy-meta-analysis.pdf`; the benchmark's default questions are about it.
- Vaswani et al. (2017). Attention Is All You Need. <https://arxiv.org/abs/1706.03762>
  (113 links, 40 references: a good demo of DocLens reading a PDF's hidden links).
- He et al. (2015). Deep Residual Learning for Image Recognition. <https://arxiv.org/abs/1512.03385>
