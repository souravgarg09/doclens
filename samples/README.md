# Demo PDFs

Place born-digital PDFs here for demos and benchmarks. PDFs in this folder are not committed,
since research papers are usually copyrighted.

Good open-access papers to try:

- Vaswani et al., *Attention Is All You Need* — <https://arxiv.org/abs/1706.03762>
  (rich in citation and cross-reference links)
- He et al., *Deep Residual Learning for Image Recognition* — <https://arxiv.org/abs/1512.03385>
  (many tables and charts)
